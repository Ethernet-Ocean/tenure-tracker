How to read this portfolio

EVIDENCE, NOT CLAIMS

Each project shows its evidence and how far that evidence goes. A course is marked verified only when the student's own file names it. Otherwise it is marked inferred. Skills the evidence can't confirm are listed as assumed. Links to teaching-evaluation themes appear only when an artifact supports them. One student's project never stands in for a whole course.
