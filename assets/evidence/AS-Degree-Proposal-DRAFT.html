1 Program purpose

Create a degree pathway within Digital Media Arts that builds on existing certificates rather than requiring students to begin again. The initial pathway connects foundational game design, interaction and UX, 3D production, VR/XR development, and a portfolio-ready project. The longer-term goal is to map other DMA certificates into degree completion options.

Janét Hund expressed support for an A.S. that helps DMA certificates become stackable and aligns students’ declared programs with Course Program of Study (CPOS) requirements. This draft is a starting point for Ali, Colin, Counseling, and Financial Aid to refine.

2 Draft catalog description

This program prepares students to design, develop, test, and present interactive digital media experiences, including games and virtual or extended reality projects. Students apply game mechanics, user experience design, real-time multimedia production, accessibility, prototyping, and professional portfolio practices using contemporary creative technologies. The program supports career preparation, continued education, and development of transferable technical and creative skills.

3 Draft program student learning outcomes

  • Design and implement an interactive project integrating game systems, interface and user experience principles, and real-time media production.
  • Develop, test, and improve an accessible interactive or immersive experience using iterative prototyping and documented feedback.
  • Present a professional portfolio demonstrating production processes, design decisions, technical competence, and career readiness.

6 CTE and industry alignment

This is proposed as a local CTE A.S. aligned with multimedia, interactive design, special effects/animation, game production, and immersive media occupations. It uses the existing endorsed COE labor market analysis as the working workforce evidence, assuming it is accepted for the final A.S. application. The application should include the actual issued report and occupation alignment, not only a research summary.

The author’s California Clear CTE credential supports experience in career technical education. The college’s program designation and approval depend on curriculum, labor market alignment, industry consultation, and governance—not on the faculty credential alone.
