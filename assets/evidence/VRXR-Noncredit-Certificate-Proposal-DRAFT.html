Catalog Description

This program prepares students to design, develop, test, document, and present introductory virtual and extended reality experiences. Students build workforce skills in immersive design, real-time development, spatial interaction, user experience, accessibility, prototyping, testing, and portfolio presentation using current industry tools and VR hardware. Completion supports entry-level and skill-building opportunities in immersive media, interactive entertainment, simulation, visualization, training, and related digital media fields.

Program Learning Outcomes

  1. Develop a functional immersive experience using current VR and XR tools and real-time production workflows.
  2. Apply interaction design, user experience, accessibility, testing, and revision practices to an immersive project.
  3. Document and present a portfolio-ready immersive project demonstrating technical skills and workforce readiness.

Employment Outcome

The program prepares learners for entry-level, assistant, freelance, internship, and skill-upgrading opportunities involving immersive-media production, VR and XR prototyping, real-time 3D content, simulation, visualization, user testing, and interactive digital media. Final occupational alignment will be refined using the official Center of Excellence report and advisory input.

Admissions and Enrollment

  • Open admission with no additional program requirements beyond those established by the College.
  • No program-specific enrollment limitations are proposed.
  • Hardware access, safety, accessibility, and recommended preparation will be addressed within the course proposals.
